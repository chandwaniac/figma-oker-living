# Oker Living - Home Decor and Furniture E-commerce App

A production-grade React application converted from Figma designs for the Oker Living home decor and furniture e-commerce platform.

## Features

- **Home Page** with Inspiration/Shop tabs, brand spotlights, and collections
- **Product Detail Page** with image gallery, color selection, and add to cart
- **Search Page** with filters and search suggestions
- **Favourites Page** with collections management
- **Cart Page** with quantity controls and checkout
- **Profile Page** with account management

## Design System

Extracted from Figma designs:

### Colors
- Charcoal scale: #151515 (500), #666666 (100), #999999 (50), #D4D4D4 (30), #E6E6E6 (10)
- White scale: #FFFFFF (pure), #F5F5F5 (off-white)
- Accent: #F5A623 (amber)

### Typography
- Font: Inter
- Sizes: XS (10px), SM (12px), Body (14px), LG (16px), XL (18px)

### Components
- Button (primary, secondary, outline, ghost)
- Badge (default, amber, success, outline)
- Chip (selected, default)
- Input, SearchInput
- Checkbox, Radio
- QuantityCounter
- SegmentedControl
- ProductCard, BrandCard, CollectionCard

## Tech Stack

- React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- React Router DOM v7
- Lucide React Icons

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output will be in the `dist/` folder.
